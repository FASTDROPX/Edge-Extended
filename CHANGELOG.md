# Changelog

## 1.0 — First public release

- Public name: Edge Extended.
- Removed the embedded settings preview and home status tile; the main switch now fills its row.
- Removed the Material slider endpoint indicator.
- All effects, combinations and volume-button animations start off on a fresh install.
- Added English, Russian, Simplified Chinese, French and German localization with in-app language selection.
- Added a GitHub entry to the top-right menu.
- Includes light/dark/system themes, both effect-selection modes, ten optional effects and standalone visual tests.
- Pattern-based analysis is explicitly BETA.
- Published the complete project under MIT, with build instructions and automated checks.
